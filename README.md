# DS1302计时器模块
# 功能：
- 使用内置的时钟显示在lcd1602液晶屏上
- 可以更改时间

### 使用方法
1. 使用江协科技系列的51单片机
2. 接入lcd1602模块
3. 将文件夹内的所有文件编译的hex文件烧录入单片机
4. 按下独立按键S3进入更改时间模式，此时位选的时间单位闪烁显示，位选顺序为：年月日时分秒星期几
5. 使用独立键盘的s0到s8表示数字1~9,s15表示0
6. 按下s14，将保存当前值并位选下一个时间单位，在位选最后一位时将自动保存并退出更改模式
7. 按下s13将使当前输入的数据清零，当输入数据大于100时也会自动清零（有时候不好使）
8. 按下独立按键k2将直接退出时间更改模式，此前更改的时间值也会自动生效
9. 可在“ds1302.c”文件中修改ds_time数组内容来改变预设的时间值
